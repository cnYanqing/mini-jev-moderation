# Mini-Jev 图文与视频审核进展（2026-11-15）

项目包含图片、中文文字及视频抽帧审核，目标为色情／R18 裸露与可见血腥。视频复用图片判定头，不是独立时序视频模型；声音和 OCR 尚未接入。

| 验证范围 | 保留版／训练前 | 本轮候选 | 说明 |
|---|---:|---:|---|
| 图片色情，历史人审回顾 | 42/47，89.4% | 本轮未重新验收 | 小样本、部分边界有争议 |
| 文字色情，外部新提示 | 21/24，87.5% | 22/24，91.7% | 少漏检1条，仍误报2条 |
| 文字血腥，外部新提示 | 20/24，83.3% | 20/24，83.3% | 6个阳性只检出2个；候选Brier变差 |
| 视频画面血腥，新作品 | 31/37，83.8% | 同为31/37 | 无更优开发集候选，回退原权重；10阳性检出6个 |

后面三行均为AI初审标签，不是人工金标或真实平台正确率。视频42帧中5帧血腥标签待确认，有效37帧，仅2个作品组；不能与上一轮不同样本上的69.6%直接比较并声称提升。视频色情无确认阳性，不能报告召回。图片血腥历史人审集也缺阳性。

文字v1先前在48条自编留出题两类都48/48，这只能证明该自编集表现，外部新提示暴露的漏检说明不能写成实际准确率100%。

本轮新下载24个THVL视频约616MB，抽144帧；从Safety-Prompts选153条外部中文提示，加原192条自编train/dev回放。最终视频204train/101dev/42test、文字218train/103dev/24test。按已识别作品／句式家族隔离，仅q/o判定头训练，3目标×3学习率×24轮；冻结骨干、LoRA、norm、temperature和其它模态。开发集选型后冻结模型，新test一次验收，保留epoch0与失败记录。

**当前状态：图片v6及文字v1保留；新文字候选仅供研究，没有自动替换服务。** 已保存选中权重、9份实际试验末轮权重及历史视频对照权重。所有对外输出保持review_only，分数未经真实违规概率校准。

下一步优先补人工确认的具体伤口描述、正常成人话题讨论、昏暗局部伤口画面和视频色情阳性；复核抽帧漏检，再评估输入或独立LoRA。不得继续使用本轮test反复调参后称独立验收。

模型与权重：[Hugging Face](https://huggingface.co/lettery/mini-jev-moderation-image-v6)。本GitHub更新只提供项目介绍、结果与文档，不新增训练代码、权重或原始素材。
